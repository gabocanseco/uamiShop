# UAMISHOP


## Requisitos Previos

* [Node.js](https://nodejs.org) v20.x o superior
* [npm](https://www.npmjs.com) (Viene incluido con Node)

## Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/gabocanseco/uamiShop.git
cd uamiShop
```

2. Instalar dependencias

```bash
npm install
```
## Ejecución de pruebas

Utilizamos Vitest como framework de testing

```bash
npm test
```
